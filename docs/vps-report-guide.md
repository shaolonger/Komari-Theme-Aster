# VPS 全面报告 · Aster 1.9.0

在 VPS 详情页顶部点击「生成报告」，选择日期后点击「生成全面报告」。首次默认最近 7 天，可切换最近 24 小时、30 天、本月或直接编辑起止日期和时间；沿用主题显示时区，单份最长 366 天。详情页正在查看自定义图表范围时，该日期会预填到报告表单。

## 阅读与保存

报告分为八章：报告概览、性能资源、网络质量、带宽流量、运行稳定性、配置资产、事件建议、数据口径。左侧导航切换章节；手机上导航移到顶部。图表可以悬浮或点击查看点值，展开数据表可查看前 200 个返回点，全部输入保存在报告内置 JSON 中。

- **下载原格式 HTML**：保留全部章节、趋势图、明细、规则、数据和生成时外观。无需原站、登录态、外部字体或图表服务，断网后直接用浏览器打开。原站后续更新、退出登录或历史数据过期均不改变本地文件。
- **数据 JSON**：在报告右上角下载本次实际采用的输入与派生统计。原始点与聚合桶精度会明确记录，不能把聚合结果当成原始探测明细。
- **打印 / 存为 PDF**：打开浏览器打印窗口，选择「存为 PDF」。所有章节与关键证据表格按顺序展开，打印样式使用浅色；大规模采样点表格和原文 JSON 不重复打印，完整数据仍在 HTML/JSON 内。

报告生成后可以调整日期重新生成；每次生成都有新的报告 ID 和截止时刻。只改表单不会改变已生成的档案。页面刷新会回到保留日期的生成表单；需要再次生成或打开先前下载的 HTML，不会把重新查询结果冒充原快照。

## 数据与权限

报告沿用当前用户能读取的节点与指标权限；只有登录用户才读取管理端补充资料。默认隐藏 IP 与检测目标，脱敏同时应用于正文、隐藏明细和 JSON；「可选设置」中可以显式选择包含完整地址。

历史资源包含 CPU、内存、Swap、负载、磁盘占用、上下行速率、累计流量、进程数、TCP/UDP 连接；GPU/温度只在后端确实返回值时列入。网络章节汇总已有 Ping，以及网络观测 v3 的路由、大陆/国际测速、国际连通、IDC、BGP/RPKI，并兼容旧版 v2/v1 保留记录。该功能**不会触发新的测速或探测**，也不需要为生成资源报告额外安装网络插件。

网络检测按完成时间归入所选范围；跨区间开始的测量单独说明。已过期明细仅保留真正可读的摘要，不能重新展开逐跳结果。不同来源、方向、协议、连接数和端点的检测分别保留，不合并为一条线路评分。旧版接口只提供当前保留集合，报告会声明无法保证覆盖完整历史。

令牌、Cookie、密码、私有备注、探测器凭证和未经白名单筛选的命令原文不会进入档案。节点名称与备注按文本处理，不作为 HTML 执行。完整地址选项只影响当前有权读取的地址，不会绕过权限获取私有目标。

## 如何理解数值

- **范围与缺测**：查询严格使用所选起止时间 `[start, end)`，不使用只能查询「最近 N 小时」的旧 REST 回退替换日期。超出保留期、接口拒绝访问或部分请求失败时，仍可保存已成功生成的章节，具体影响见「数据口径」。
- **平均、峰值与 P95**：资源均值使用返回点间距推断时间权重，权重不会跨越缺口。单点时只能得到采样值。峰值和 P95 只描述返回点或桶均值，不能还原桶内真实瞬时峰值与原始分位数。官方容量分母缺失时，不会制造历史容量。
- **Ping**：成功时延按成功探测样本数加权；失败数/总样本数决定丢包。超时不计为 0ms。权重缺失或不一致时，不能恢复的统计显示为不可用。
- **流量**：计算相邻累计计数器增量，VPS 上传/下载分别记录。回退段不累加，边界不精确和缺测会标记为部分覆盖，已观测量可能低估。跨午夜的增量归入后一采样日期。当前套餐配额与所选期间量分别呈现，不替代供应商账单。
- **稳定性**：采集覆盖按返回点间距估计，不等于在线率或 SLA。没有历史在线/重启事件时不计算历史在线率，也不将缺测写成已确认停机。当前在线状态与 uptime 是生成时快照。
- **资产**：厂商、价格、周期、到期、系统、容量和 Agent 等为生成时配置。报告不能还原历史扩容与价格变化，也不会把当前续费配置标作实际支出。
- **前期比较**：可选项默认关闭。资源只有在精度相同、双方覆盖充分且查询未受限时才计算变化；前值为 0 时显示绝对变化。Ping 保留同任务 ID 的两期均值，但历史目标和协议配置无法完整核实时不计算增减百分比。

报告不会凭空补齐 IO/IOPS、硬盘健康、容器、应用日志、漏洞扫描等未采集数据，也不会生成没有依据的综合健康分数。事件建议描述已有证据，不能自动证明故障根因。

## 资源限制与故障处理

单次网络 HTTP 响应最多 16 MiB、整份输入最多 32 MiB、最终 HTML 最多 20 MiB。v3 每模块最多查询 100 页，测量记录约 1500 项和 16 MiB 的初始预算；达到预算时明确标记覆盖受限，超出整份文件限制时提示缩小日期范围。图表会减少绘制点，但统计使用全部已取得的有效输入。

正在生成时可取消；取消会停止后续取数和计算，不覆盖此前报告。网络插件未安装时，资源、Ping 与配置仍可归档。网络检测列表暂不支持按日期服务端过滤，因此首次长范围报告可能需要逐页查询；进度显示实际阶段，不显示虚构百分比。
