# VPS 全面报告 · Aster 1.32.1

在 VPS 详情页顶部点击「生成报告」，选择日期后点击「生成全面报告」。首次默认最近 7 天，可切换最近 24 小时、30 天、本月、全部历史，或直接编辑起止日期和时间；沿用主题显示时区。全部历史从 1970 年起查询，图表按最早可读取的观测调整展示起点；前一等长区间比较在全部历史模式下不可用。详情页正在查看自定义图表范围时，该日期会预填到报告表单。

## 阅读与保存

报告分为八章：报告概览、性能资源、网络质量、带宽流量、运行稳定性、配置资产、事件建议、数据口径。左侧导航切换章节；手机上导航移到顶部。概览先呈现结论、使用率圆环和关键趋势，资源统计与逐项证据收进可展开明细。图表可以悬浮或点击查看点值，全部已取得输入保存在报告内置 JSON 中。

- **下载 HTML / 下载含图片 HTML**：保留全部章节、趋势图、明细、规则、数据和当前选定的完整检测结果；先生成所选 PNG，再内嵌到文件。无需原站、登录态、外部字体或图表服务，断网后直接用浏览器打开。原站后续更新、退出登录或历史数据过期均不改变本地文件。
- **数据 JSON**：在报告右上角下载本次实际采用的输入与派生统计。原始点与聚合桶精度会明确记录，不能把聚合结果当成原始探测明细。
- **打印 / 存为 PDF**：先生成并解码所选图片，再打开浏览器打印窗口，选择「存为 PDF」。所有章节按顺序输出，使用浅色；技术明细默认不打印，完整数据仍在 HTML/JSON 内。所选完整检测结果图片直接显示在网络章节。

报告生成后可以调整日期重新生成；每次生成都有新的报告 ID 和截止时刻。只改表单不会改变已生成的档案。页面刷新会回到保留日期的生成表单；需要再次生成或打开先前下载的 HTML，不会把重新查询结果冒充原快照。

## 完整检测结果、高清图片与样式

网络质量章节的「完整检测结果画廊」列出所选日期内仍可读取的 TcpQuality / NodeQuality 结果，每次保留独立日期、轮次、状态和上游链接。支持逐项勾选、搜索、分页、选择全部、清空，以及每类最新一份；默认选中每类最新一份。选择只控制附带的高清图片；HTML 保留所有已收集轮次及原报告链接，即使清空勾选也不会清空历史。搜索条件不带入离线档案。打印使用所选图片，网络统计仍描述原查询范围。数据 JSON 导出当前档案中的完整采集快照。

- **统一图表版（默认）**：依据本轮真实 CSV / JSON / 保留输出生成统一蓝白图表与分页结果。缺失与失败保留实际状态，不补造成功结果。点击缩略图可以放大或下载单张 PNG。
- **上游原始版**：TcpQuality 读取官方报告的原始 SVG 分区；NodeQuality 使用已保留的终端输出，保留上游深色配色、ANSI 颜色与等宽列布局。这里保留的是报告内容外观，不包含上游网页的导航栏和按钮。长结果连续分页。
- **高清图片 ZIP**：导出当前所选轮次、当前样式的 PNG，宽度至少 2400 像素；按模块、检测时间和轮次分目录。`results.json` 附带每轮原报告链接、时间与图片样式。PNG 本身已压缩，ZIP 使用无损存储。

在 **Aster 工作室 → 外观 → 报告与导出** 设置默认样式并保存；生成表单和画廊也能临时切换。已有设置默认使用统一图表版。

TcpQuality 原始图片需要将面板网络观测插件更新到 **1.21.1**，且生成图片时可访问对应官方报告。只从已保存轮次的官方链接读取图片，不接受任意地址。探测器仍为 **1.14.0**，无需为此重装或重置凭证。NodeQuality 原始版需要该轮仍保留终端日志。若原始图片接口返回主题 HTML，说明对应插件接口尚未启用，需要覆盖升级并重新启用插件。上游已删除、未保存日志或明细已过期时会明确提示，可取消选择该轮或切回统一版；不会用统一版冒充原始版。

含图片 HTML 已内嵌所选 PNG，可离线查看和重新下载。离线切换到尚未归档的 TcpQuality 原始版，需要回到在线页面取得图片后重新保存。

## 网络观测历史趋势

历史趋势改为类别与测点选择器，每次只绘制「主要趋势」与「对照趋势」两张图。不同方向、地址族和协议继续分开；展开明细只显示当前两条趋势的最近观测，完整已采集记录仍在 JSON 中。Ping 采用单任务切换，并以独立任务的时延条形图辅助比较，避免几十张图和大表同时展开。

## 数据与权限

报告沿用当前用户能读取的节点与指标权限；只有登录用户才读取管理端补充资料。默认隐藏 IP 与检测目标，脱敏同时应用于正文、隐藏明细和 JSON；「可选设置」中可以显式选择包含完整地址。

历史资源包含 CPU、内存、Swap、负载、磁盘占用、上下行速率、累计流量、进程数、TCP/UDP 连接；GPU/温度只在后端确实返回值时列入。官方后端还保留每张 GPU 的使用率、显存使用/容量、温度以及设备索引、名称和聚合精度，设备之间不会合并覆盖。上报流量增量另列，与累计计数器计算出的期间量分开，避免对聚合桶均值重复求和。网络章节汇总已有 Ping，以及网络观测 v3 的路由、大陆/国际测速、国际连通、IDC、BGP/RPKI。网络趋势按实际测点、城市、运营商、协议、地址族、方向和连接数区分；线路以观测类别展示，不能证明购买的商业线路产品。该功能**不会触发新的测速或探测**，也不需要为生成资源报告额外安装网络插件。

网络检测按完成时间归入所选范围；跨区间开始的测量单独说明。已过期明细读取仍保留的逐目标摘要与数值，不能重新展开逐跳结果。插件目前保留约 7 天原始明细和 90 天轮次摘要；已删除的历史无法恢复。不同来源、方向、协议、连接数和端点的检测分别保留，不合并为一条线路评分。旧版接口只提供当前保留集合，报告会声明无法保证覆盖完整历史。

结构化完整结果移除令牌、密码等凭证字段；保留日志屏蔽常见凭证赋值与授权头。默认地址脱敏同时应用于明细、PNG、上游矢量和 JSON。原报告链接仍可访问上游原站，其内容与权限由上游管理。节点名称与备注按文本处理，不作为 HTML 执行。完整地址选项只影响当前有权读取的地址，不会绕过权限获取私有目标。

## 如何理解数值

- **范围与缺测**：查询严格使用所选起止时间 `[start, end)`，不使用只能查询「最近 N 小时」的旧 REST 回退替换日期。超出保留期、接口拒绝访问或部分请求失败时，仍可保存已成功生成的章节，具体影响见「数据口径」。
- **平均、峰值与 P95**：资源均值使用相邻点的局部采样间距推断时间权重，权重不会跨越缺口。长期聚合与近期采样的间隔不同，不能只用一个全局间隔判断断线；旧后端的最近四小时分开查询，以避免被长周期查询再次粗化。单点时只能得到采样值。峰值和 P95 只描述返回点或桶均值，不能还原桶内真实瞬时峰值与原始分位数。官方容量分母缺失时，不会制造历史容量。
- **Ping**：成功时延按成功探测样本数加权；失败数/总样本数决定丢包。超时不计为 0ms。权重缺失或不一致时，不能恢复的统计显示为不可用。
- **流量**：计算相邻累计计数器增量，VPS 上传/下载分别记录。回退段不累加，边界不精确和缺测会标记为部分覆盖，已观测量可能低估。跨午夜的增量归入后一采样日期。当前套餐配额与所选期间量分别呈现，不替代供应商账单。
- **稳定性**：采集覆盖按返回点间距估计，不等于在线率或 SLA。没有历史在线/重启事件时不计算历史在线率，也不将缺测写成已确认停机。当前在线状态与 uptime 是生成时快照。
- **资产**：厂商、价格、周期、到期、系统、容量和 Agent 等为生成时配置。报告不能还原历史扩容与价格变化，也不会把当前续费配置标作实际支出。
- **前期比较**：可选项默认关闭。资源只有在精度相同、双方覆盖充分且查询未受限时才计算变化；前值为 0 时显示绝对变化。Ping 保留同任务 ID 的两期均值，但历史目标和协议配置无法完整核实时不计算增减百分比。

报告不会凭空补齐 IO/IOPS、硬盘健康、容器、应用日志、漏洞扫描等未采集数据，也不会生成没有依据的综合健康分数。事件建议描述已有证据，不能自动证明故障根因。

## 资源限制与故障处理

单次网络 HTTP 响应最多 16 MiB、整份输入和最终 HTML 各最多 128 MiB。网络记录最多 100,000 项，网络预算约 64 MiB；达到预算时明确标记覆盖受限，超出文件限制时提示缩小日期范围。旧后端对近期数据按最多一周分段读取，较早范围逐步扩大；返回点达到上限时继续拆分。每类数据最多 256 次查询、150,000 条记录，达到上限时优先保留近期数据并标记受限。各网络模块的逐条证据正文最多展示最近 10 条，每个趋势表最多展示最近 50 条，其余已收集记录保存在 HTML 内的 JSON。图表会减少绘制点，但统计使用全部已取得的有效输入。完整结果单个分区最多保留 400,000 字符，截断时明确标记；新生成 PNG 每批最多 80 MiB，ZIP 和含图片 HTML 最多 128 MiB，超出后可分批选择导出。

正在生成时可取消；取消会停止后续取数和计算，不覆盖此前报告。网络插件未安装时，资源、Ping 与配置仍可归档。网络检测列表暂不支持按日期服务端过滤，因此首次长范围报告可能需要逐页查询；进度显示实际阶段，不显示虚构百分比。
