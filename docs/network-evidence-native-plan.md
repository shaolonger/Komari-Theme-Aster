# 网络证据与原生测量整合

本次范围：线路证据、统一卡片、原生 TCP 质量、公共大陆测速、定时与历史。沿用 v3 方案/任务/轮次，不恢复旧脚本入口。

## 验收约束

- ASN、注册网络、产品声明分开；AS4809 不自动认证 CN2 GIA，AS23764 不自动认证 CTG GIA。跨运营商证据不得丢失。
- 未知 ASN 保留，CN2 注册地址段补充网络证据，不伪造 BGP ASN；卡片不拼接不同轮次的路径。
- 卡片等高且可触摸展开；状态说明终点确认与测量覆盖，不再用模糊的“部分”。
- 原生 TCP 检测区分完整建连、SYN 探测、包长响应及 socket 重传；不可用时注明原因，不用估算替代实测。
- 公共测速严格匹配实际城市/运营商/地址族，保留真实端点与时序；区分接收端计量、发送端计量、均值与峰值。
- 所有测量支持现有 VPS/分组、时区定时、轮次历史，测速限额/互斥/超时/取消；失败不计作成功的零速。
- 不执行或分发上游原始脚本；参考公开设计独立实现。第三方端点覆盖与协议变化必须如实记录。

## 实施顺序

1. 统一网络规则、归属补查、主页投影与报告证据。
2. 原生 TCP 质量模块及可选能力；公共测速适配器和流量限制。
3. 配置、报告、趋势及全主题卡片布局。
4. 回归、真实 Komari 运行时、浏览器检查、打包与发布。
