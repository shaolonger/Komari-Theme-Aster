# Aster 独立交互重构

目标：移除面向用户的上游主题体验，重新实现 Aster 配置系统与独立视觉语言，并通过实际浏览器验证后发布。历史贡献和来源应准确记录；更名或删除署名不是原创性证据。

## 当前证据

- 2026-09-11：配置入口仍是 2,200 行左右的长表单，包含大量散落的独立草稿状态、通用实例面板与底层 UUID / 筛选表达式编辑。
- 首次实现新的 SettingsStudio / StudioPanel、独立样式、五个任务分区、分区搜索、草稿状态提示。各区保持挂载，切换不丢失草稿。
- 首次变更 typecheck 与 lint 通过。尚未完成浏览器验证，不代表整体重构完成。
