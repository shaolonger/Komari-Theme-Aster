# 首页三网卡片展示策略（1.16.0）

需要主题 **1.16.0** 与网络观测插件 **1.13.0**；探测器仍为 **1.10.0**，无需重装或重置凭证。

工作室 → 网络观测 → **主页三网线路**：

- 「线路展示方式」默认“优选线路”，每格只显示一个已观测网络。切换“完整线路”后，以 ` + ` 连接该格全部观测网络。
- 「显示同路径、差异与终点确认说明」默认关闭，可单独开启。

工作室 → 网络观测 → **主页三网测速**：「显示接收端计量、TCP 已确认等说明」默认关闭，可单独开启。

点击各面板的「保存显示与发布范围」立即保存至插件，并在管理员与获授权的访客卡片上应用；三个选项独立保存，重启后保留。原有节点发布范围独立管理。IPv4 / IPv6 切换和最近测试时间继续显示，点击线路 / 速度结果仍可查看详细证据及计量说明。

## 优选名称如何选择

| 同类网络 | 摘要展示优先级 |
| --- | --- |
| 电信 | CN2 ＞ CTGNet ＞ 163 |
| 联通 | 9929 ＞ 10099 ＞ 4837 |
| 移动 | CMIN2 ＞ CMI ＞ 9808 |

每行分为三级。例如 `163 + CN2` 选 CN2，`4837 + 9929` 选 9929，`9808 + CMI + CMIN2` 选 CMIN2。跨运营商的同级网络保留原始观测顺序，不额外制定运营商品质排名；未知网络保留其实际名称。没有有效观测时保留失败 / 无覆盖状态，不借用其他方向、地址族或历史成功结果。

这是卡片名称的展示策略，不能代替实测延迟、丢包或带宽排序。某一城市观测到优先级较高的网络，不表示其他城市也经过它，更不表示整个路径只有这一网络。完整模式和点击展开均保留这些差异；详情继续显示实际 ASN 序列与终点确认状态。

CN2、CTGNet 是可观测的网络；CN2 GIA、CTG GIA 等属于商业产品属性。本策略只选择实际观测标签，不把 AS4809 或某段 59.43 地址单独当作 GIA 认证。路由识别、ASN / 地址段证据和原始报告不因展示设置而改变。

## 参考脚本的取舍

核对的上游源码固定到以下提交，未执行或嵌入其原始脚本：

- [NodeQuality a92fca6](https://github.com/LloydAsp/NodeQuality/blob/a92fca6c0067df29ddd03fdc2fee6f3000f64545/NodeQuality.sh) 的网络报告主要委托 NetQuality。
- [NetQuality d5b9948](https://github.com/xykt/NetQuality/blob/d5b99484d51286374d24b892c1b54235dc282148/net.sh) 根据主干 ASN 与路径特征选取摘要名称，遇到 AS9929 / AS58807 时提升对应摘要；也包含 CN2 GT / GIA 的路径启发式。
- [TcpQuality 708ba0b](https://github.com/ibsgss/TcpQuality/blob/708ba0b073a63b10fa8894fb09174e12d01aa665/runTcpQuality-core.sh) 在部分分支优先 9929，并保留 `10099→9929`、`CMIN2→CMI` 等组合，也使用 GIA 启发式；并非总是单一标签。

Aster 采用明确、可切换的单一摘要名称选择规则，并将商业产品认证与路径观测分开。完整观测不会因摘要精简而删除。

## 运行开销

设置只影响共享摘要和前端呈现，不发起新的探测。已发布节点仅切换展示选项时，不重扫历史路由报告；首次发布新节点或管理员明确重建摘要仍按已有流程生成缓存。首页继续按页面共用分钟级摘要请求，不逐卡轮询。
