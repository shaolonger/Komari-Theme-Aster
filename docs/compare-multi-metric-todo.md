## 设计原则

- 单指标体验保持不变，多指标作为增强模式进入。
- 结果默认优先回答“谁最差、差在哪、是否同步异常、数据是否可信”。
- 不把不同单位硬叠在一张大图里；用统一风险分驱动颜色和排序，用原始值保留真实语义。
- 支持所有指标自由多选：CPU、内存、磁盘、负载、下行、上行、连接、延迟、丢包。
- 多指标主视图采用诊断矩阵：行是 VPS，列是指标，每个单元格展示风险等级、主数值、最新值、迷你趋势和异常标签。

## 实施记录
