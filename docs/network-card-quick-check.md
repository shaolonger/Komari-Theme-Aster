# 卡片三网快捷检测

主题 1.19.0 / 插件 1.16.0。探测器协议和采集功能沿用 1.12.0，此次无需重新安装或升级探测器。

三网线路和三网测速同时保留，不用标签页隐藏另一项。测速地区并入标题行，IPv4 / IPv6 保持各模块独立切换；线路去掉重复方向箭头，缩减表头与单元格间距。最近测试以月日与时分显示，完整时间和时区仍在提示与详情中。优选 / 完整线路、计量说明开关及单元格的证据抽屉继续有效。长线路在固定高度内省略，完整内容可通过提示和详情读取。触屏按钮保留额外点击空间，六种外观共用布局。

管理员登录后，切换到目标地址族，点击标题右侧的检测图标。只执行当前 VPS 对应的大陆线路或大陆测速模块，沿用已有目标、协议、来源、时长和流量预算；不会同时运行方案中的国际检测等其他模块，也不会创建默认测速方案。多个方案匹配时，优先最近使用的匹配方案，否则使用首个已启用的匹配方案。没有配置当前地址族时，图标进入该 VPS 的方案配置。测速继续要求方案已接受流量说明，公共测速保持全局排队和冷却。

重复点击复用正在执行的同范围轮次。卡片显示排队或检测状态，以已收尾目标数计算进度；未配置的测速九宫格单元不计入检测工作量。100% 表示本轮已收尾，不等于所有目标成功；全部成功、部分成功、失败与报告不可用各自标记。结果刷新后短暂高亮，失败不闪烁旧的绿色结果。系统开启“减少动态效果”时停用旋转、扫光与闪烁，文字和进度仍显示。

手动检测的轮次引用保存在当前标签页会话，刷新后继续观察，不自动重新测量；引用最多保留六小时。进度连接暂时中断时保留已有进度并重连，服务器测量继续。切换卡片布局和地址族不影响已发起任务；完整报告仍可从原证据详情与 VPS 网络检测页打开。

前端通过页面级状态存储只更新相关卡片，进度最多每五秒合并读取，每批不超过 64 个轮次；没有手动检测或已全部收尾时不发送进度请求，标签页隐藏时不做后台间隔轮询。完成时合并刷新相关模块的主页摘要，不逐卡片请求摘要。后端进度读取当前轮次清单与任务索引，不遍历历史报告或返回完整路由原始数据。

快捷执行和进度接口均须管理员身份。访客只能阅读已发布摘要，不显示快捷按钮，服务端也拒绝执行请求。旧插件不返回快捷能力标记时，主题仍可展示已有摘要；升级插件后再使用快捷检测。现有发布范围、显示开关、计划和凭证不变。
