# 原生网络测量与线路证据

适用主题 1.13.1、插件 1.10.1、探测器 1.9.1。

## 线路

ASN 是观察 IP 的来源归属证据，登记地址段是另一种证据，不相互改写。AS4809 记 CN2；AS23764 记 CTGNet；59.43.0.0/16 的 APNIC CN2-BB 登记仅补充网络名称，不伪造 AS4809。所有其他 ASN 也完整保留。跨运营商承载不按目标运营商过滤。

CN2、CTGNet 网络与 CN2 GIA、CN2 GT、CTG GIA 商业产品不属于同一层级。出现某个 ASN 或特征地址不足以证明服务产品。节点手动标签是用户声明，报告的产品状态为未核验。运营商资料：

- https://www.chinatelecomeurope.com/dbicapac/ （AS23764 同时承载 GIA 和 Global Transit）
- https://www.chinatelecomeurope.com/wp-content/uploads/ChinaTelecom_Global-Internet-Service.pdf
- https://wq.apnic.net/apnic-bin/whois.pl?object_type=inetnum&searchtext=59.43.0.0

MTR 保留其实际逐跳统计。可用的独立 NextTrace 观测只按相同 IP 补充元数据，不按相同 TTL 拼路径；未匹配 IP 不借用相邻跳归属。后端依次补查 Team Cymru 和 RIPE RIS，使用统一超时和缓存。终点未确认时，末跳 100% 未响应不能作为端到端业务丢包。

探测器 1.9.1 允许保留有位置、WHOIS、运营商或域名但没有 ASN 的同 IP 元数据。ASN 来源和查询时间与 GeoIP 来源分别保存；BGP 补查不会覆盖已有位置。NextTrace 补充固定到本次 MTR 已解析的目标 IP，并关闭地图生成，避免地图服务错误阻止 JSON 输出。

报告同时展示网络名称、位置库标注、WHOIS、域名和可用的 PTR，支持展开来源。位置标签仅供参考，不作为已验证的物理路径；折叠同 AS 时保留元数据不同的分段。独立 NextTrace 路径、RTT、协议/端口、时间、退出码、解析失败及输出节选均可展开查看，绝不计入 MTR 统计。输出按原有 48k 协议限额截断，截断有明确标记。

历史报告中未采集的位置不会自动补造。旧报告与旧探测器仍可读取；需要新采集信息时更新对应 VPS 的探测器并重新检测，不需要重置密钥。集中升级服务不包含在本次修复中。

主页仅汇总最新一轮，逐项保留城市、协议、时间及 ASN 序列。不同测量之间的 ASN 并集不画成连续路径。公共摘要不发布 IP、探测器身份、凭证或原始报告。

## TCP 质量

基础模式采集 3/5/10 次完整 TCP connect，成功样本计算中位数、均值、极值和标准差；失败保留 timeout/refused/failed。失败率不是 IP 数据包丢包率，全部失败不会产生 0ms。

可选 nping 原始 SYN 及 0/512/1200 字节载荷比较。需要工具与 CAP_NET_RAW；未取得响应可能来自过滤或回包限速，不认证业务丢包或 PMTU。未安装工具时明确缺测，不自动修改权限、内核或 TCP 参数。

吞吐测试使用实际测试 socket 的 Linux TCP_INFO 或 iperf3 发送端信息；不使用主机总重传差值、不把 RTT/2 叫作实测单向延迟。TCP_INFO 不可用时保留缺测；公共上行可保留明确标注的本地写入估算。没有远端发送侧计数时不声称已测下载发送端重传。

## 公共测速

Aster 自行实现目录发现、会话、传输采样和清理，不运行或分发参考项目脚本/二进制。参考互操作接口：

- https://github.com/MiaM1ku/taierspeedtest/tree/ed67e6e92ca189afe29ef07eba0815fe56bda62d
- https://github.com/ibsgss/TcpQuality/tree/708ba0b073a63b10fa8894fb09174e12d01aa665

不复制 TcpQuality 的 GPL-3.0-only 源码，也不复制没有明确许可证的泰尔客户端实现；这里的测量、任务及 UI 是 Aster 独立实现。公共资源和协议的可用性不由 Aster 保证。

目录仅通过固定 HTTPS 地址发现；数据端点必须是公网 IP，城市、运营商与地址族严格匹配。目标目录的声明和实际服务器 ID/IP/名称/匹配依据一起保存，不用未匹配城市冒充所选城市，不使用任何公共图床或报告上传服务。会话校验值只用于协议互操作，临时会话标识不写入报告。

下载记录 HTTP 接收的实际载荷，拒绝 HTTP 错误与压缩替换。上传优先记录 Linux TCP 已确认字节；这不等于服务器应用接收量。缺少计数时标“本地写入估算”，不会称作接收端均值。提前 HTTP 拒绝不生成有效速率。平均速度来自整个有效采样期间，峰值仅取完整秒；保留时间序列，绝不把最高几次采样均值当作全程均值。

每点流量上限包括预热和所有连接数/方向，按应用载荷统计，协议开销另计。达到预算提前结束的样本标明原因；失败和缺测保持空值。调度沿用 v3，每节点/公共服务串行、计划错峰、无数据繁忙退避；取消终止真实 socket 并释放会话。

历史汇总保留 90 天、原始样本 7 天。趋势按同一目标/P1/方向查看，端点或计量方法变化时断开连线，避免把节点变化误读为线路性能变化。
