# 曜石外观与首页三网线路

Aster 1.11.1 增加「曜石」和「曜石·明」。两者按提供的移动端参考图组织卡片：地区和地址族标签、四宫格资源指标、分段进度、上下行趋势、流量配额、逐任务网络质量和三网线路。曜石使用石墨灰底色，曜石·明使用对应的冷白浅灰配色；两者共享同一布局。

首页右上角展开快捷按钮即可切换。Aster 工作室 → 外观 → 默认外观可保存站点默认值；个人选择优先。支持刷新恢复与工作室隔离预览。

## 网络质量

沿用首页网络绑定，可以同时显示多条任务的延迟、丢包与历史。默认优先展示最需关注的三条任务，超过三条可展开；任务名称仍可进入该任务的 VPS 对比。

曜石标准 / 扩展卡片将延迟、丢包分别绘成两条 24 格时间条。时间格从实际保留样本生成；灰色代表缺测，失败探测保留丢包，降采样样本按探测次数计算部分丢包，不能将缺测当作零丢包。显示的总丢包数字仍采用现有服务端统计口径。紧凑卡片保留原来的多任务折线布局。

CPU、内存、磁盘与负载、网络速率、流量配额继续读取真实 Komari 数据。参考图中的 19%、459 ms、CN2 等是示例数值，不会固定写入主题。上下行总量标为“累计”，直接使用后端计数器，避免将计数器值误称为自然月统计。右下角金额按钮可展开在线、到期、标签和续费价。

## 配置三网线路

此功能同时支持浅色、深色、跟随系统、诊断、澄空和曜石两套外观。标准、扩展、紧凑卡片直接显示；列表中可展开「三网线路」。

1. 更新主题至 **1.12.0**，网络观测插件至 **1.9.0**。安装包附带 **1.8.0 runner**，建议同步升级。安装与登记方法见[网络观测指南](../network-observatory/README.md)。
2. 在实例的网络观测或工作室的网络设置中配置 v3「大陆路由」方案。为电信、联通、移动选择允许探测的端点或大陆测量点；IPv4 和 IPv6 分别配置方案。
3. VPS → 大陆测量产生**回程**，大陆测量点 → VPS 产生**去程**。去程需要受控大陆测量点或可用的公共观测覆盖；仅安装 VPS runner 不会自动得到去程。
4. 完成检测后，管理员首页直接预览摘要；打开**工作室 → 网络观测 → 主页三网线路**，勾选需要公开摘要的可见节点，保存显示与发布范围。首次升级会回填仍保留的新版路由明细，也可手动重建摘要。
5. 首页使用一个全局摘要请求，每分钟刷新一次；后台暂停刷新。首次安装或无插件时不持续请求。无需修改 Komari 或 Agent。

默认不发布任何节点。摘要仅包含节点 UUID、运营商、线路标签、ASN、方向、采样时间与状态，不包含目标地址、测量点身份、凭证或原始报告。隐藏和删除节点被排除；隐藏标记在插件下一次清单刷新后生效。旧插件未记录公开状态的清单不会用于发布。

已有外观在没有测量时保持紧凑布局；管理员不需要先向访客发布即可预览。曜石保留参考图的三网区域，并说明安装或发布步骤。插件请求失败显示暂不可用；未探测方向显示「未探测」，IPv6 不会套用 IPv4 数据，去程和回程不会互相复制。

## 线路标签含义

标签根据实际 MTR / 路径观测的 ASN 生成，不根据 Ping 任务名称、节点标签或延迟猜测线路。例：电信 AS4809 → CN2、AS4134 → 163；联通 AS9929 / AS10099 / AS4837；移动 AS58807 → CMIN2、AS58453 → CMI、AS9808。

电信对 CN2 / AS4809 的对应关系见[运营商资料](https://www.chinatelecomeurope.com/wp-content/uploads/ChinaTelecom_Global-Internet-Service.pdf)，移动对 CMIN2 / AS58807、CMI / AS58453 的对应关系见[运营商资料](https://mainwebapi.cmi.chinamobile.com/uploads/template/20251216272c9a10af6d23e3b7c459e04e91bf4b.pdf)。ASN 注册信息可从 [APNIC RDAP](https://rdap.apnic.net/autnum/9929) 核对。

同一观测中经过多个网络时保留组合标签；同一天不同城市 / 协议观测不一致时保留不同结果。悬停标签可以查看 ASN、时间和观测组数。路径未到达终点标为「部分」，超过 24 小时标为「过期」，超过 7 天不再作为当前线路显示；新失败会覆盖相同目标的旧成功记录。没有可识别的 ASN 标为「未识别」。这些标签描述已观测的网络，不保证 CN2 GIA 等商业产品属性，不代表全部地区或未来路由。

## 验证

`npm run test:release-gates` 覆盖单元测试、插件 / runner 测试、类型、lint、RPC 契约、性能预算与浏览器回归；`npm run test:plugin-runtime` 验证官方 Go 插件运行环境。

仅运行曜石浏览器用例：

```sh
npm run build
BROWSER_SLATE_ONLY=1 BROWSER_SLATE_SCREENSHOT_BASE=/tmp/aster-obsidian/preview node scripts/browser-scale-gates.mjs
```

浏览器回归涵盖两套外观的保存 / 默认值 / 刷新 / 预览、IPv4/6 独立数据、单向缺测、多任务展开、金额面板、四种视图与 320–1440px 布局，以及原有外观的线路展示。
